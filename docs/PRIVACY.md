# Setu — Privacy Policy

Effective 11 November 2026. Applies to the Setu server and its plugin.

## Data collection

SETU has no accounts, analytics, telemetry or advertising. It runs on your own computer and the
developer receives nothing from it.

## Usage and storage

- SETU talks to the EasyEDA Pro app on your computer through EasyEDA's local API gateway
  extension, over 127.0.0.1 only (ports 49620–49629). It reads and changes the project you have
  open in EasyEDA Pro when you ask it to.
- Files you export (manufacturing files, schematic images, project backups) are written to
  your computer, in Documents/SETU unless you choose another folder.
- Parts searches run through EasyEDA Pro's own library service, as they do when you search in
  EasyEDA yourself.
- What Claude sees is whatever the tools return in your conversation; that conversation is
  handled by Anthropic under Anthropic's own privacy policy.

## Third-party sharing

SETU itself sends nothing to anyone. The plugin's launcher downloads SETU's server once from
this project's GitHub releases (github.com/NextBuilder/Setu) if it is not installed yet.

## Data retention

Everything SETU writes stays on your computer until you delete it.
